# Mayurika

Персональная кицунэ-помощница. Согласованная архитектура — 90 функций. Реализация поэтапная.

## Этап 1: Foundation

Уже создано: Python HTTP API (только localhost), SQLite с WAL и внешними ключами, таблицы диалогов и памяти, точная дедупликация, источники, события, FTS5 с резервным LIKE-поиском, интерфейс TypeScript + Canvas + CSS, BAT-запуск.

**Не реализовано:** облачный чат, embeddings, смысловой поиск, полноценная проверка фактов, SOUL CORE, самообучение, агенты и остальные функции из 90. Записи имеют статус pending, а не verified.

## Запуск на Windows

Нужны Python 3.10+ и уже установленный компилятор TypeScript (`tsc`). Запусти `Mayurika.bat`. BAT не скачивает зависимости. Откроется http://127.0.0.1:53554. Данные — `data/memory.sqlite3` (исключены из Git).

## API

- GET /api/health
- GET /api/events
- GET /api/memory/search?q=...
- POST /api/memory с JSON `{"content":"..."}`

**Безопасность:** это локальный прототип без полноценной аутентификации. Не публикуй его в интернет и не сохраняй секреты в репозитории.

## Стек

TypeScript + HTML5 Canvas + CSS, Python — единственный API, Node.js — только frontend, SQLite — единственная локальная база. Облачные LLM и embeddings подключим отдельно после проверки совместимости. Никаких новых зависимостей без согласования.
